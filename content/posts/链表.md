## C++ 构造函数与析构函数总结

### 1. 构造函数（Constructor）

构造函数是在 **创建对象时自动调用的函数**，主要用于 **初始化对象的成员变量**。

特点：

- 函数名与类名相同
    
- 没有返回值
    
- 创建对象时自动执行
    

例如：

MyLinkedList() {  
    dummyhead = new LinkedNode(0);  
    size = 0;  
}

当创建对象：

MyLinkedList list;

构造函数会自动执行，完成链表初始化。

---

### 2. 析构函数（Destructor）

析构函数是在 **对象生命周期结束时自动调用的函数**，主要用于 **释放资源（如 new 分配的内存）**。

特点：

- 函数名为 `~类名()`
    
- 没有参数和返回值
    
- 对象销毁时自动调用
    

例如：

~MyLinkedList() {  
    LinkedNode* cur = dummyhead;  
    while (cur != nullptr) {  
        LinkedNode* temp = cur;  
        cur = cur->next;  
        delete temp;  
    }  
}

用于释放链表中所有节点，防止内存泄漏。

---

### 3. 类的使用方式

在 `main` 函数中创建对象并调用成员函数：

int main() {  
    MyLinkedList list;  
  
    list.addAtHead(10);  
    list.addAtTail(20);  
  
    cout << list.get(0) << endl;  
  
    return 0;  
}

程序结束时，析构函数会自动执行，释放链表内存。

---

### 总结

- **构造函数**：对象创建时自动调用，用于初始化对象
    
- **析构函数**：对象销毁时自动调用，用于释放资源
